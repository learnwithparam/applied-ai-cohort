# Failure modes

Every failed label in `evals/labels.jsonl` belongs to exactly one mode below.

## rate-per-acre

Definition: The grower writes the rate per acre, and the record gives the same number with the unit L/ha.
Count: 3
Emails: TB-1006, TB-1017, TB-1025

## field-guessed

Definition: The email does not name one field clearly, and the record names a field anyway.
Count: 3
Emails: TB-1026, TB-1029, TB-1034

## product-not-in-catalogue

Definition: The record names a product that is not in the co-op's product list, because the grower misspelled it.
Count: 2
Emails: TB-1008, TB-1024
